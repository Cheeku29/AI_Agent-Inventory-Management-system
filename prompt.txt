Build a production-quality end-to-end AI Inventory Intelligence
platform for dark stores / warehouses.

The product should improve existing inventory software rather than
replace it.

The most important requirement is that the application must NOT be
hardcoded to my development dataset.

My existing dataset will be used for development, ML training,
testing and evaluation.

The final application must allow a NEW END USER to:

1. Sign up / sign in using Google
2. Create an account
3. Upload their own inventory-related CSV/Excel/Parquet files
4. Let the AI automatically understand the uploaded data
5. Map their columns to a canonical inventory schema
6. Validate the data
7. Determine which AI capabilities are possible
8. Run ML and inventory intelligence analysis
9. Generate inventory recommendations
10. Show the recommendations in a visual dashboard
11. Show exactly which products should be ordered
12. Explain WHY each product should be ordered
13. Allow the user to approve/reject recommendations
14. Maintain an action history

The system must be dataset-agnostic.

============================================================
1. PRODUCT CONCEPT
============================================================

Build an AI Inventory Intelligence Copilot for dark stores,
warehouses and quick-commerce operations.

The system should answer:

- What products are likely to stock out?
- What products should we order?
- How much should we order?
- When should we order?
- Which products are overstocked?
- Which inventory records look abnormal?
- Which products may expire before being sold?
- Which inventory may be phantom inventory?
- Which actions should the inventory manager prioritize?
- Why is the AI recommending this action?

The product is an intelligence layer on top of existing
inventory software.

It must not assume that the company is using my exact database
schema.
